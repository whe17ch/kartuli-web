# Kartuli Web — Design Specification (from mockups)

## Aesthetic
"Retro Pixel · Warm · Friendly" — pixel-art illustrations + clean modern UI. Calm, encouraging, kind. "No XP. No leaderboards. No pressure."

## Color Palette (UPDATED from mockups)
- Rose Red: #D23F5A (primary CTA, buttons, active nav, headers, progress bars)
- Mint: #7DBE9F (hearts, streaks, online status, checkmarks, success)
- Sky Blue: #6DA8FD (mic button, link text, transliteration, info accents)
- Warm Cream: #FFF4E3 (page background, overall canvas)
- Ink: #2A2A2A (primary text, headings)
- Slate: #9ABF98 (muted text, inactive states)
- Card White: #FEFCF7
- Card Border: #E5DFD3
- Gold: #D7A623 (rewards, milestones)
- Purple: #8A5CF6 (minimal accent)

## Typography
- **Headings / Brand / Section Labels**: Pixel bitmap font (use "Press Start 2P" from Google Fonts). ALL CAPS, letter-spacing 1-2px. Used for: "KARTULI", "CONTINUE LESSON", "TODAY'S WORD", "DAILY CULTURAL FACT", "THIS WEEK", button text
- **Georgian brand subtitle**: ქართული in same pixel font style
- **Body / UI text**: System sans-serif (Inter or SF Pro). Weights: 400, 500, 600
- **Font sizes**: Brand 32-40px, section labels 11-13px, card titles 16-18px, body 14-15px, small labels 10-12px, Georgian lesson content 28-36px

## Card System
- Background: #FEFCF7 (off-white)
- Border: 1px solid #E5DFD3
- Border-radius: 12-16px
- Shadow: 0 2px 8px rgba(0,0,0,0.05)
- Padding: 16-20px internal
- Section labels ABOVE cards in pixel font, rose red, all caps, ~11px

## Buttons
- Primary CTA: Rose red bg, white text in PIXEL FONT, all caps, border-radius 8-10px, right arrow →, subtle bottom shadow for 3D press effect
- Secondary: Rose red text links with → arrow
- Audio/Mic: Sky blue rounded square, white icon

## Navigation (Bottom Tab Bar)
- 5 tabs: Home / Learn / Tandem / Culture / Profile
- Active: Rose red fill icon + rose red label
- Inactive: Slate/gray outlined icon + gray label
- Background: white/cream, top border 1px

## Top Navigation
- Left: ← back arrow
- Center: Screen title, semi-bold, 18px
- Right: Heart (rose) or bell icon
- Home variant: "KARTULI ქართული" in pixel font, bell icon right

## Progress Bars
- 4px height, light gray track (#E5E5E5), rose red fill
- Heart icon + "1 / 31" counter preceding

## Decorative Elements
- Cross-stitch floral ornaments in top-right corners
- Small cross/plus marks (+) in rose at corner accents
- Pixel art hearts (♥) scattered as accent
- Pixel art spot illustrations: potted plants, sleeping cats, flowers, mountains in info sections
- Cross-stitch vine/branch separators
